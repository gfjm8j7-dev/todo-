تداول صالح PRO — نسخة PWA كاملة
================================

المحتويات:
index.html            التطبيق
manifest.webmanifest  اسم التطبيق + شكل التثبيت + الأيقونات
sw.js                 التخزين المؤقت والعمل بعد التحميل
icons/               أيقونات 192 و512

التثبيت على الجوال:
1) ارفع مجلد التطبيق إلى استضافة HTTPS مثل GitHub Pages أو Netlify أو Vercel.
2) افتح الرابط في Chrome على الجوال.
3) اضغط زر "تثبيت" داخل التطبيق، أو من قائمة Chrome اختر "تثبيت التطبيق / إضافة إلى الشاشة الرئيسية".

مهم: فتح index.html كملف محلي file:// لا يسمح عادةً بتسجيل Service Worker، وبالتالي لا يعطي PWA كاملة. HTTPS أو localhost مطلوب.

البيانات: محفوظة محليًا في LocalStorage داخل المتصفح/التطبيق.
