تداول صالح PRO — نسخة PWA كاملة
================================

🔹 index.html — واجهة التطبيق
🔹 manifest.webmanifest — إعدادات التثبيت والأيقونات
🔹 sw.js — التخزين المؤقت والعمل بدون اتصال
🔹 icons/ — أيقونات التطبيق (192 و512)

التثبيت على الجوال:
1) ارفع مجلد التطبيق إلى استضافة HTTPS مثل GitHub Pages أو Netlify أو Vercel.
2) افتح الرابط في Chrome على الجوال.
3) اضغط زر "تثبيت" داخل التطبيق، أو من قائمة Chrome اختر "تثبيت التطبيق / إضافة إلى الشاشة الرئيسية".

مهم:
- فتح index.html كملف محلي (file://) لا يسمح عادةً بتسجيل Service Worker، وبالتالي لا يعطي PWA كاملة.
- HTTPS أو localhost مطلوب لتفعيل جميع ميزات التطبيق.
- بعد أول تحميل للتطبيق عبر الإنترنت، يمكن استخدامه بدون اتصال بفضل التخزين المؤقت في Service Worker.
- عند صدور تحديث جديد، أغلق التطبيق وأعد فتحه لتحديث الكاش تلقائيًا.

البيانات:
محفوظة محليًا في LocalStorage داخل المتصفح/التطبيق.
